# Agent 协作中心

本目录集中保存多 AI 派单、技术交接和真机部署门禁。

## 读取顺序

1. `AGENTS.md`：行为与安全规则。
2. `AI_PROTOCOL.md`：单主写者和多 AI 协作流程。
3. GitHub Issue：当前工单范围、证据和验收。
4. `HANDOVER.md`：稳定的项目背景和接手信息。

## 内容

- `issue-tracker.md`：GitHub Issues 工单操作规范。
- `deployment.md`：打包、上传、安装和真机验收门禁。
- `GLOSSARY.md`：项目统一术语。
- `github/`：GitHub 工单模板与标签说明。
- `adr/`：架构决策记录。
