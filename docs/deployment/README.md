# 打包与真机部署门禁

## 阶段

1. **目标机只读盘点**：架构、OS/ROS/Python、磁盘、时间、网络、设备接口、运行进程和已安装依赖。
2. **生成清单**：列出源码、厂商程序、配置、离线依赖、版本和文件 SHA256。
3. **本地验证**：从干净目录解包，执行离线安装和构建测试。
4. **上传**：仅传输并比对 SHA256，不同时安装或启动。
5. **安装与构建**：备份同名目录，安装缺失依赖，单独构建并记录结果。
6. **无运动启动**：核对节点、话题、频率、载荷和唯一命令发布者。
7. **分级真机验收**：急停可用 → 单臂低速安全位 → 工作空间边界 → 双臂 → 中断/恢复。

## 打包默认排除

- `.git/`、`build/`、`install/`、`log/`、`__pycache__/`
- 录包、日志、core dump、临时监控数据
- SSH 密钥、token、口令、用户主目录配置
- 未经审查的设备唯一标定和历史备份

## 必须产物

- `MANIFEST.txt`：文件列表。
- `SHA256SUMS`：包及重要文件校验值。
- `VERSIONS.md`：构建端和目标端版本。
- `INSTALL.md`：安装和回滚步骤。
- Issue 中的部署与验收证据。
