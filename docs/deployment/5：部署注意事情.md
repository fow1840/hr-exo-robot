# 5：部署注意事情

1：就是网段要一致

2：是需要考虑部署得机器人得性能，选择内存和芯片比较好的部署环境

3：messagebridge和puppertry最好是放在同一个环境里

4：IK和FK，可以随意放到不同的环境里

3：看下双臂线程是否会卡顿，卡顿得话需要改成单臂双线程

4：urdf如何确认和真机是一致得呢？

5：需要在机器上找到对应的机器人的关节状态话题和关机控制话题

6：然后我们需要把机器人的关节状态话题转换成-----/client\_robot/joint\_states

机器人IK逆解后得到/target\_robot/joint\_commands-------转换成对应的机器人的关机控制话题信息

7：同时配置的时候也要注意pupptry发布的频率不需要太高，会严重影响到设备的运行。
8：其他的话题也是频率太高会影响运行

9：真机调试出问题时按标准动作取证：先抽话题频率、再 `bash scripts/collect_logs.sh 1`
打包运行日志（fk/ik 节点输出自动落盘在 `~/.ros/log/`，屏幕与落盘同内容），
日志逐行含义见《4：FK_和IK_的配置部署》§9.2 速查表；新问题落账到 `agent/LEDGER.md`。
